# tech-stack-010226

**One-line purpose:** Next.js reference app for a dated tech stack (Jan 2026) — chat, tables, shadcn patterns.

## Prerequisites

- Node.js `24.16.0` or newer Node 24 LTS patch (see `.nvmrc`)
- pnpm `11.6.0` (pinned via `packageManager` in `package.json`)

```bash
corepack enable
corepack prepare pnpm@11.6.0 --activate
pnpm install
```

## Run locally

```bash
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000).
